# Uniform Shop Website 🏫

A Django-based website for school uniform shops with loyalty points system.

## Features
- Product listing
- Loyalty points system
- WhatsApp integration
- Mobile friendly

## Tech Stack
- Python & Django
- HTML, CSS, JavaScript
- SQLite Database

## Setup
```bash
pip install django
python manage.py migrate
python manage.py runserver
```
