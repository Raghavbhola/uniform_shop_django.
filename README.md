# 🏫 Uniform Shop Website

A Django-based website for a school uniform shop with a customer loyalty points system. Customers earn points based on their purchases and receive updates through WhatsApp.

## ✨ Features

* 🛍️ **Product Listing** – Browse available school uniforms.
* 🎁 **Loyalty Points** – Customers earn points based on their purchases.
* 📱 **WhatsApp Notifications** – Customers receive a thank-you message with their earned and remaining points.
* 🧮 **Automatic Calculation** – Purchase amounts and loyalty points are calculated automatically.
* 📱 **Responsive Design** – User-friendly interface across devices.

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Integration:** WhatsApp Messaging

## 🚀 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Raghavbhola/Uniform-Shop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Uniform-Shop
   ```

3. Install Django:

   ```bash
   python -m pip install django
   ```

4. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

5. Start the development server:

   ```bash
   python manage.py runserver
   ```

6. Open `http://127.0.0.1:8000/` in your browser.
